## How to use these inside the generator

If you'd rather *not* paste these by hand, you don't have to.
Run `npm run generate:pins` and the system will:

1. Read every product in `data/products.json`.
2. Pick 3 different formulas from this set per product.
3. Auto-fill `{HOOK}` and `{PRODUCT}` per pin.
4. Output `content/pinterest/pins.csv` ready for **Canva → Apps → Bulk Create → Connect data**.

That's the no-manual-work path. This file is the manual-fallback / inspiration deck.
